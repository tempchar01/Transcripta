# Transcripta desktop UI

Transcripta is a restrained, single-window Windows utility. It uses Segoe UI Variable (with Segoe UI fallback), a compact header, one centred workspace, visible one-pixel control borders, and a neutral blue primary action.

The two supported themes are Graphite (dark) and Pearl (light). Both use opaque conventional desktop surfaces: no transparency, gradients, glow, decorative background, avatar, sidebar, settings surface, or animated UI material.

The workspace moves only between Empty, File loaded, Processing, and Ready. Qt layouts own scaling at 100%, 125%, 150%, and 200% DPI. The only exported user result is DOCX.
