# Accessibility / Доступность

Transcripta aims to provide a readable Windows desktop interface in English and Russian with light and dark themes. Full accessibility compliance, screen-reader compatibility and complete keyboard navigation have not been independently verified. Report barriers via GitHub Issues, including application version, Windows version, display scaling, assistive technology and reproduction steps. Avoid sharing private files.

Transcripta стремится обеспечить читаемый интерфейс Windows на русском и английском языках со светлой и тёмной темами. Полное соответствие стандартам доступности, совместимость с экранными дикторами и полная клавиатурная навигация независимо не подтверждены. Сообщайте о проблемах через GitHub Issues с указанием версии приложения, Windows, масштабирования, вспомогательных технологий и шагов воспроизведения. Не публикуйте личные файлы.
