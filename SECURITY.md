# Security policy / Политика безопасности

Report suspected vulnerabilities privately to tempchar1@outlook.com. Include the affected version, environment, reproduction steps and potential impact. Do not post exploitable details or private files in public issues. Use the latest available release when possible. No fixed response SLA or support period is promised. Please coordinate public disclosure with the maintainer.

Сообщайте об уязвимостях конфиденциально на tempchar1@outlook.com. Укажите версию, окружение, шаги воспроизведения и возможные последствия. Не публикуйте детали эксплуатации и личные файлы в открытых задачах. По возможности используйте последний релиз. Фиксированные сроки ответа и поддержки не гарантируются. Согласуйте публичное раскрытие с автором.
