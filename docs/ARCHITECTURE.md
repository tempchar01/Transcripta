# Архитектура

```
GUI (PySide6) → TranscriptionJob → FFmpeg chunk stream → faster-whisper + VAD
                                      ↓                     ↓
                                WAV одного фрагмента    Segment[]
                                      ↓                     ↓
                              удаление временного WAV → atomic checkpoint → exporters
```

`ui` не импортируется из engine-кода. `core` хранит независимые `Transcript`, `Segment`, `Word`. Экспортёры получают только `Transcript`, поэтому SRT и DOCX не влияют на распознавание.

## Длинные файлы

Источник не декодируется целиком. FFmpeg по одному создаёт моно WAV 16 kHz; production duration выбирается hardware profile, а `RecognitionSettings.chunk_seconds` — internal-only override для integration/endurance runs (не меньше 30 секунд). После успешной попытки фрагмента `checkpoint.json` заменяется атомарно. При следующем запуске идентичность файла (абсолютный путь, размер, mtime), модель, язык и длительность сверяются; только совпадающая задача возобновляется.

Это даёт границу восстановления в один фрагмент. Отмена и пауза безопасны между сегментами/фрагментами; текущий вызов ASR нельзя принудительно прервать без риска повредить нативный inference.

## Ошибки

Полный traceback записывается в лог. UI показывает короткое сообщение. Ошибка отдельного аудио-фрагмента не стирает завершённые фрагменты и не останавливает оставшиеся; пользователь получает предупреждение. Ошибка загрузки GPU делает одну попытку CPU fallback.

## GPU profiles and OOM

`hardware.gpu` отделяет обнаруженную NVIDIA-карту от доступного CUDA backend CTranslate2. `hardware.profiles` выбирает `AUTO`, `MEMORY_SAVER`, `BALANCED`, `QUALITY` или `CPU`. Профиль логируется перед ASR.

При CUDA OOM текущий аудио-фрагмент повторяется ограниченно: `float16` меняется на `int8_float16`, затем выбирается более короткая стратегия для следующих фрагментов, затем `Auto` переключается на CPU. Выбранная деградация хранится в checkpoint и используется при resume. Явный режим `GPU` не переключается молча — задача сообщает, что нужен выбор CPU/Auto. Peak RAM измеряется Windows API, VRAM — выборками `nvidia-smi`; второе значение не является непрерывным NVML profiler.
