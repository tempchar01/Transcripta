# Transcripta brand system

Product name: **Transcripta**. The production icon is `assets/branding/generated/app_icon.ico` and is shared by the frozen executable and installer.

The visual direction is a clean local Windows utility: Graphite and Pearl themes, Segoe UI Variable typography, restrained spacing, and no decorative character, motion, glass, neon, or sci-fi elements. Russian and English use the same typographic hierarchy.
