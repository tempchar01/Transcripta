# Transcripta UI system

The product is a compact, single-screen transcription workflow. The header contains **Transcripta**, the local-only subtitle, and RU/EN controls. The main workspace presents an empty drop target, a loaded-file waveform with three selectors, compact progress, or the finished-document actions.

Graphite and Pearl are opaque native-looking palettes. Controls use subtle borders, modest radii, and explicit hover, pressed, disabled, and keyboard-focus states. The interface has no avatar, Command Glass surface, sidebar, settings page, animation controller, or technical implementation copy.

`Новая транскрибация` preserves the existing reset flow. `Открыть документ` and `Открыть папку` retain their existing system actions. The footer exposes the creator contact links only after an explicit click.
